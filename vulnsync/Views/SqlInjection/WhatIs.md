## What is Sql Injection?
**Sql Injection** is a security vulnerability that occurs when an attacker is able to manipulate a SQL query by inserting malicious input. This often happens when user input is directly included in SQL queries without proper validation or escaping. It can allow attackers to retrieve, modify, or delete data from a database, potentially compromising the entire system.
