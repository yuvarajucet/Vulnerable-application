# Understanding Open Redirects

An open redirect is a type of security flaw found in web applications where a user is redirected to a `different website` or `page` based on `user-supplied input`. These vulnerabilities occur when a web application accepts untrusted input that could alter the destination page for a redirect. An attacker can manipulate this functionality to redirect users to malicious websites, potentially leading to phishing or other types of malicious behavior.
