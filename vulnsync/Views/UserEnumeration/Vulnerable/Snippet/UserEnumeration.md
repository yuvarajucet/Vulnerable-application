## Vulnerability to User Enumeration

The following images demonstrate a vulnerability that exposes user information through specific messages.

![Vulernable1.png](Assets/Image/UserEnumeration/Vulernable1.png)
![Vulernable2.png](Assets/Image/UserEnumeration/Vulernable2.png)

When specific messages indicate whether a username or email exists (e.g., "Username already taken" or "Invalid password"), it allows attackers to infer valid usernames or emails. This information can be exploited for further attacks.
